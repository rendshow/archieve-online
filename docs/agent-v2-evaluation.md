# Agent V2 评测约定

## 当前已自动化的层

`src/test/resources/agent-v2/benchmark/task-spec-smoke.json` 是最小任务规划回归集。每条用例固定用户表达、页面范围、预期意图、工具和证据要求；它用于防止新增规则破坏已经确认的路由行为。

运行：

```powershell
mvn test "-Dtest=AgentV2TaskSpecBenchmarkTest"
```

## 后续基准集格式

完整基准集在正式档案完成页级 OCR 和 OpenSearch 同步后建立。每条案例至少应有：问题、范围、目标档案、目标字段、预期页码、期望状态和人工审核标记。

未审核的 Excel 行只能作为待审候选，不参与准确率计算。已审核行将导出为 JSONL，并分别计算档案定位、字段抽取、表格、证据引用和正确拒答指标。

## 指标解释

- `Recall@5`：正确档案是否出现在前五个候选中。
- `Top1 Accuracy`：第一候选是否为正确档案。
- 字段准确率：值和字段语义均正确，例如毕业证日期不可用学位授予日期代替。
- 引用准确率：回答的每一个事实是否能回到正确档案和页码。
- 正确拒答率：索引不足、证据不足或范围冲突时是否正确停止，而不是给出推测答案。
